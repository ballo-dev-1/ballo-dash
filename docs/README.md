The canonical reference for all platform stats API responses in BalloDash. This document defines:
- Standardized response structure across all platforms (Facebook, Instagram, LinkedIn, X)
- Field definitions and type specifications
- Platform-specific implementations and metrics
- Usage examples and best practices
- Migration guides and validation guidelines

**Use this as your primary reference** when working with any platform stats APIs.
